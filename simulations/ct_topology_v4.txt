EXECUTIVE SUMMARY & TOPOLOGY CONFIRMATION (PHASE 1.1)
================================================================================
HYPOTHESIS CONFIRMED:
Each of the 6 CT primaries in TransformerWithCTSaturation.slx is connected in a
current-divider bridge circuit with parallel and series 0.5 ohm resistors.

1. High-Voltage (HV) Side:
   - Phase A: Line current from Primary_side splits into two parallel branches:
       Branch A1: 'Series RLC Branch3' (0.5 ohm) -> Step_down_Transformer Port 1
       Branch A2: 'CT' (primary Conn1->Conn2) in series with 'Series RLC Branch6' (0.5 ohm) -> Step_down_Transformer Port 1
   - Phase B: Line current from Primary_side splits into:
       Branch B1: 'Series RLC Branch4' (0.5 ohm) -> Step_down_Transformer Port 2
       Branch B2: 'CT1' (primary Conn1->Conn2) in series with 'Series RLC Branch7' (0.5 ohm) -> Step_down_Transformer Port 2
   - Phase C: Line current from Primary_side splits into:
       Branch C1: 'Series RLC Branch5' (0.5 ohm) -> Step_down_Transformer Port 3
       Branch C2: 'CT2' (primary Conn1->Conn2) in series with 'Series RLC Branch8' (0.5 ohm) -> Step_down_Transformer Port 3

2. Low-Voltage (LV) Side:
   - Phase A: Current from Step_down_Transformer Port 4 splits into:
       Branch a1: 'Series RLC Branch' (0.5 ohm) -> Secondary_side Port 3
       Branch a2: 'Series RLC Branch11' (0.5 ohm) in series with 'CT4' (primary Conn1->Conn2) -> Secondary_side Port 3
   - Phase B: Current from Step_down_Transformer Port 5 splits into:
       Branch b1: 'Series RLC Branch1' (0.5 ohm) -> Secondary_side Port 4
       Branch b2: 'Series RLC Branch10' (0.5 ohm) in series with 'CT3' (primary Conn1->Conn2) -> Secondary_side Port 4
   - Phase C: Current from Step_down_Transformer Port 6 splits into:
       Branch c1: 'Series RLC Branch2' (0.5 ohm) -> Secondary_side Port 5
       Branch c2: 'Series RLC Branch9' (0.5 ohm) in series with 'CT6' (primary Conn1->Conn2) -> Secondary_side Port 5

PHYSICAL CONSEQUENCES:
- In each phase, the CT primary branch has ~0.5 ohm + Z_CT, while the bypass branch has 0.5 ohm.
- The CT primary carries almost exactly 50% of the true phase conductor current (1 / 2.024).
- Effective CT ratios measured in probe_ct_truth.m (HV 809.6:1, LV 16,925:1) are exactly 2.024x
  the nameplate transformer winding ratios (HV 400:1, LV 92000/11 / 5 = 1,672.7:1).
- The equivalent per-phase impedance (0.25 ohm net series resistance) chokes low-voltage
  through-faults to ~1.5 pu and causes the LV bus voltage to sag under full load.

ACTION FOR PHASE 1.2:
- In TransformerWithCTSaturation_v4.slx, re-wire all 6 CTs so each CT primary carries 100% of the
  phase line current in direct series:
    HV: Primary_side -> CT primary (Conn1->Conn2) -> Step_down_Transformer
    LV: Step_down_Transformer -> CT primary (Conn1->Conn2) -> Secondary_side
- Delete or bypass the 0.5 ohm parallel/series resistor pairs:
    HV: delete/bypass Series RLC Branch 3, 4, 5, 6, 7, 8
    LV: delete/bypass Series RLC Branch, 1, 2, 9, 10, 11
- Keep shunt ground capacitance branches (Branch 12, 13, 14, 15, 16, 17) intact if needed.
