# Reference Papers Catalog

In accordance with publisher copyright regulations and academic distribution licenses, third-party published journal articles, conference papers, and textbook chapters are **not** hosted directly in this repository.

To access or inspect the cited literature:
- Consult [REFERENCE_DOWNLOAD_SHEET.md](REFERENCE_DOWNLOAD_SHEET.md) for the complete bibliography, verified DOIs, direct publisher access links (IEEE Xplore, ScienceDirect/Elsevier, SpringerLink, MDPI, De Gruyter), and open-access repositories.
- Citations in the thesis LaTeX source (`latex_source/latex/references.bib`) directly match the literature indexed in the reference download sheet.
