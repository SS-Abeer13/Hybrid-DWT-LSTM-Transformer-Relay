# Tools and External Integrations

This directory is reserved for local helper utilities, co-simulation bridges, and Model Context Protocol (MCP) server plugins.

## MATLAB MCP Server
If you are integrating MATLAB/Simulink co-simulation via the Model Context Protocol (MCP):
- Obtain the official `matlab-mcp-server` bundle directly from MathWorks or the official MathWorks repository.
- Due to binary size (~29 MB) and third-party software licensing, `.mcpb` bundles are excluded from version control via `.gitignore`.
